# Student Registration Form 📝

A clean, responsive, and well-structured HTML form designed for collecting student registration and academic details. This project is built as part of my HTML practice and web development learning journey.

---

## ✨ Features

* **Comprehensive Data Fields:** Includes fields for full name, email, age, gender selection, courses, skills, and address.
* **Interactive Elements:** Implements text inputs, number fields, radio buttons, checkboxes, dropdown menus, and submit/reset buttons.
* **Clean Layout:** Well-organized structure for easy readability and styling integration.

---

## 🛠️ Code Implementation & Elements Used

In this project (`student_form.html`), the following HTML tags and input types have been implemented:

* **Heading & Form Container:**
  * `<h1>`: Used for the main title ("Student Registration form").
  * `<form>`: The container wrapping all form controls.
* **Input Fields:**
  * `<input type="text">`: For capturing the user's **Full name** (with `required` validation).
  * `<input type="email">`: For capturing the **Email** address (with `required` validation).
  * `<input type="number">`: For entering the user's **Age**.
* **Selection Controls:**
  * `<input type="radio">`: For choosing **Gender** (Male / Female options).
  * `<select>` & `<option>`: Dropdown menu for selecting a **Course** (CSE, ECE, Mechanical).
  * `<input type="checkbox">`: For selecting multiple **Skills** (C++, Python, HTML).
* **Multi-line Input & Buttons:**
  * `<textarea>`: For entering the **Address** (configured with rows and columns).
  * `<button type="submit">`: Button to **Register** (submit) the form.
  * `<button type="reset">`: Button to **Reset** the form fields.
